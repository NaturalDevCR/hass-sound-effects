# Sound Effects

Sound Effects brings a managed sound library to Home Assistant. It pairs a Supervisor App,
**Sound Effects Studio**, where you upload, edit, normalize and organize sound effects, with a
HACS integration (`sound_effects`) that picks a sound by category and season and hands your
automations a playable URL.

> **Work in progress.** This repository is under active development and is not ready for use
> yet. Full installation and usage documentation will land with the first release.
